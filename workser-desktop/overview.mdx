Workser Desktop is the installed app that lets an AI agent — Workser's own hosted one, or a coding-agent CLI you already run — actually work on your computer instead of staying inside a chat window. It bundles two distinct abilities in one app:

<Note>
Computer Use and Orbit are independent subsystems that don't require each other — see the [Orbit FAQ](/orbit/faq) for how they relate, and [Enterprise vs. Consumer](/enterprise-vs-consumer) for how Workser Desktop compares to Workser Business (the web platform).
</Note>

## What stays local vs. what goes to the cloud

| Stays local | Goes to Workser's cloud |
|---|---|
| Encrypted credential store (your OS keychain) | Screenshots and action results during a computer-use session |
| Activity/bridge logs | Deploy, git, environment variable, domain, and billing calls (Orbit) |
| Orbit session handshake | — |
| Your coding agent's own prompts, reasoning, and generated code | — |

## Pricing

Computer Use runs on the same credit-based plans as Workser Business. Orbit's hosting side needs a paid plan too (Spark and up), but doesn't charge Workser AI credits for code generation — see [Orbit's pricing section](/orbit/pricing) and [Payments & Billing](/consumer/payments-billing) for the full breakdown, including the 7-day free Spark trial every new organization gets.
