## Download

The current public Workser Code download supports **Macs with Apple silicon**. Windows is on the waitlist. Download from [workser.ai/code](https://workser.ai/code), then follow [Install & setup](/workser-desktop/install-setup).

## Local work and cloud services

Coding agents work with the local project folder and their available tools. A connected agent uses its provider account; Workser's built-in agent uses managed model access and Workser credits. Local development stops when the required local process is no longer running.

Shared project records, source sync, deployments and managed infrastructure use Workser services. Published apps run on their hosting. [Agent Cloud](/code/agent-cloud) runs product agents independently of your local coding session.

For screen tasks, the Computer Use service processes the screen context and action results needed for the task. For coding and project data flows, read [Security & approvals](/code/security-and-approvals).

## Pricing

The desktop app is free to download. New organizations start on the Free plan with no card required. Web plans start at $20 a month; Spark ($10) is sold only in the desktop app. Connected coding-agent usage, built-in agent credits and other hosted AI usage have different billing paths. See [Plans and cloud usage](/code/pricing).
