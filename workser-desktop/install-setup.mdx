## 1. Download and install

Download Workser Desktop for your platform (macOS or Windows) from your Workser dashboard.

## 2. Sign in

Sign in with the same account you use for Workser Business — your organization, connections, and credits carry over.

## 3. Grant permissions for computer use

If you plan to use the computer-use agent, macOS will prompt for **Screen Recording** and **Accessibility** permissions the first time you enable a capability that needs them (e.g. taking a screenshot, or controlling the keyboard). Windows will prompt for the equivalent OS-level permissions. You can review and revoke these at any time in your OS's privacy settings.

<Frame>
  <img src="/images/workser-desktop/install-setup/notifications-bar.png" alt="Workser Desktop notifications bar" />
</Frame>

<Note>
Workser Desktop does not request webcam or microphone access unless you explicitly use a voice-interaction feature, and sensitive folders are blocked from agent access by default.
</Note>

## 4. Set up the browser extension (optional)

Install the Workser Chrome extension if you want browser automation in addition to native computer control. It only communicates with your locally-running Workser Desktop app.

## 5. Connect Orbit (optional)

If you already use a coding-agent CLI (Claude Code, Codex, or OpenCode), open **Orbit** in Workser Desktop and follow the connection flow — see [Orbit](/orbit/overview). Orbit detects installed, already-authenticated CLIs automatically; it doesn't install or sign one in for you.
