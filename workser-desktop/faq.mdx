description: "Installation, permissions, agent connections and local versus cloud work."
---

<AccordionGroup>
  <Accordion title="Which installer should I use?">
    Use the current Mac download from [workser.ai/code](https://workser.ai/code) for Apple silicon. Windows is on the waitlist. Follow the published installation instructions rather than bypassing an unexpected operating-system security warning.
  </Accordion>
  <Accordion title="The agent cannot capture my screen or control input">
    Check Screen Recording and Accessibility permissions in macOS System Settings. Grant only the permissions needed for the capability you use. See [Install & setup](/workser-desktop/install-setup).
  </Accordion>
  <Accordion title="Workser Code does not detect my coding agent">
    Confirm that its CLI is installed and authenticated. Claude Code, Codex, Cursor Agent, GitHub Copilot and OpenCode are supported alongside the built-in Workser agent. Follow the provider sign-in flow in the connection screen. [Connect your agent](/code/connect-your-agent).
  </Accordion>
  <Accordion title="Do I need another AI subscription?">
    You can use a supported provider account you already have. The built-in Workser Code agent needs no separate provider subscription, but uses Workser credits for paid models. The cloud plan and model usage are separate. [Pricing](/code/pricing).
  </Accordion>
  <Accordion title="Does all my project data stay local?">
    No. Connected coding agents use their model provider; the built-in agent uses Workser-managed model access. Project collaboration, sync and deployment use cloud services. [Security & approvals](/code/security-and-approvals).
  </Accordion>
  <Accordion title="Can the project keep running when I close the app?">
    Published software runs on its hosting, and Agent Cloud handles hosted product agents. Local coding work requires your Mac and the relevant tools to keep running.
  </Accordion>
  <Accordion title="What happens after the trial?">
    Choose a paid plan to continue using paid cloud features. Trial expiry does not itself delete project data. See the organization's Billing view and [Payments & billing](/consumer/payments-billing).
  </Accordion>
  <Accordion title="How do I revoke computer-use access?">
    Revoke Screen Recording and Accessibility permissions in macOS System Settings. Disconnecting a coding agent and revoking computer-use permissions control different capabilities.
  </Accordion>
</AccordionGroup>
