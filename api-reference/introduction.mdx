Workser exposes project, task and publishing APIs for the existing web platform. Workser Code also provides a local CLI for development operations and a server-side SDK for the software you build.

| Interface | Use it for |
| --- | --- |
| [Workser CLI](/code/cli) | Provisioning, deployment, logs, domains and project operations during development |
| [Workser SDK](/code/sdk) | Database, storage, connections, workflows and Agent Cloud calls from your app's backend |
| Project API | Reading and managing web-platform projects |
| Task API | Creating and inspecting web-platform tasks and their results |
| Publish API | Publishing and inspecting web-platform deployments |

The endpoint pages in this reference describe the web-platform API. Do not treat a legacy Task API request as the contract for a Workser Code team task or Agent Cloud run. Follow the relevant endpoint schema and credential scopes.

Keep project credentials on your server. Authenticate and authorize your own app users before making a scoped Workser call on their behalf.
