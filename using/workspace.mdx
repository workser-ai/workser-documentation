**A project in Workser is Chat plus the tabs you open beside it, with Settings over the top.** Chat is where you ask for
work; a tab is where a thing lives while you work on it — a computer, a file, a record, an app, a result. Tabs belong to
the chat that opened them, so switching chats brings back that chat's tabs, not the last thing you looked at.

## Open a tab

- **From Chat:** a Task that makes a file, result, app or record offers it as a card. Open the card and the tab appears.
- **From the "+" beside the tabs:** search anything, or start something new. See [the launcher](#the-launcher).
- **From a link:** `?open=` opens a tab, and an old project address redirects to the same tab.

A tab keeps its state while you switch away and back. Closing a tab with unsaved edits asks first.

**Keys, on a Mac:** ⌘K opens the launcher from anywhere in the workspace, ⌥T opens it from the tab strip, ⌥1–9 jumps to a
tab, ⌥[ and ⌥] move between tabs, ⌥W closes the current one, and ⌥\ shows or hides the whole column.

## The 20 kinds of tab

| Tab (what it is called) | What it holds |
| --- | --- |
| **App** | One built app: Preview, Design, Code, Cloud and Versions. With no app chosen, the Apps gallery and its templates. |
| **Task** | One Task: its thread, steps and approvals. |
| **Changes** | What a Task changed: files, a diff, and Preview, Publish or Undo. |
| **File** | One file, with the icon for its type and a preview. |
| **Result** | Everything one Task made: documents, sheets, slides, images, pages. |
| **Computer** | A live cloud computer or sandbox, or the list of the project's computers. |
| **Browser** | The cloud browser's profiles and sign-ins. It is **not sold today**; a project without it says "Not switched on for this project yet" and web tasks use the computer's browser. |
| **Phone** | An AI agent's number, calls, summaries, transcripts and voice settings. With no agent chosen, all calls. |
| **Email** | An AI agent's inbox, sent and received. With no agent chosen, every inbox. |
| **Conversations** | The chat-app inbox: messages from WhatsApp, Telegram, Slack, Discord and LINE. |
| **Card** | The project card, what AI agents bought, their limits and single-use cards. |
| **Automations** | Standing work: how each Automation starts, on or off, and Run now. |
| **Data** | Business records: a table of customers, orders, products and more, or one record. |
| **Connector** | A connected app's own records, read-only. |
| **Web page** | A plain https page in a sandboxed frame, for looking something up without leaving Workser. |
| **Cloud** | Workser Code's cloud: app data, users, storage, environment, payments, connections, domains, deploys, logs and usage. |
| **Workser Code** | Code, Design, the project's plan and decisions, workflows, memory and saved files. |
| **Watch** | A running Task's live desk. With teammates, every screen, the plan and the team talk. |
| **Documents** | The Library: files you made or uploaded, folders, share links, status and due dates. |
| **Creative** | Design work: posts and ads, whiteboard, video, storyboard, app design, presentations and audio. |

## The launcher

The "+" beside the tabs (also ⌘K on a Mac) opens one search over the whole project:

- **Recent:** what you had open lately.
- **Search:** type two or more letters to search chats, calls, mail, purchases, files, designs and apps. A Name, a subject or
  an address is enough; a web address typed in full opens as a **Web page**.
- **Start something:** a new creative, a new app, a new Automation, or an upload.
- **Everything else:** Conversations, calls, mail, purchases, computers, browsers, phone and email, Workser Code sections,
  Cloud sections, tickets, documents, connectors, Tasks, files and business sections.

## What is not a tab

Some words are places, not tabs: **Requests** and **the morning report** live with Chat; **Settings** is the sheet; the
**Front desk** is a page under **Pages** in the sidebar. [The AI agent panel](/using/agent-panel) is the panel that opens from an AI
agent's name, not a workspace tab.
