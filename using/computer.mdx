**Every project has a shared cloud computer that all its AI agents use.** It keeps working when your laptop is closed, holds
the project's sign-ins, and is where a Task actually clicks, types and opens apps. You can watch it, take control, put it to
sleep, or reset it.

## Find it

- **The Computers tab** (from the "+" launcher or the workspace) lists every computer in the project.
- **Settings › Computers** is where you add, rename, reset or remove one.
- **One computer's tab** is its live screen, with its tools in the bar.

Computer cards show **Working**, **Asleep**, **Starting**, **Needs a restart** or **Free**, and one line about what is
happening ("Mia is working: Send the invoices"). The menu has **Open**, **Open and wake**, and **Set up sign-ins, update or
reset**. Empty: "No computers yet. Each AI agent gets a computer when it first needs one."

## Shared and dedicated computers

| | Shared computer | Dedicated computer |
| --- | --- | --- |
| Who uses it | Every AI agent in the project | Only the AI agents you choose |
| Included | Yes | **$5 a month each** |
| Sign-ins | Shared by every AI agent | Its own; the shared computer's sign-ins don't reach it |

"A dedicated computer keeps its own logins, used only by the AI agents you gave it." You choose **Who may use it** from the
project's AI agents. A computer made earlier for one AI agent is kept, free, and read-only in the list.

The number of computers working at once is a plan limit; a paused computer does not count. Only an owner or admin can add,
change or remove computers.

## Watch, wake, take control

- **Watching is free and starts by itself** for an awake computer.
- **Wake computer** is a button because it starts using computer time: "This computer is asleep. Waking it uses computer time."
- **Take control** sends your mouse and keyboard to the computer. If an AI agent is working there, it pauses before its next
  step: "Taking control pauses Mia's task until you hand the computer back. Whatever you change on the screen, Mia will find as
  you left it."
- **Give back to Mia** lets it carry on. You can add a note — "Tell Mia what you changed (optional)" — which is sent to the
  Task ("While you waited, the owner used the computer and says: …"). **Keep 30 more minutes** holds it longer.

Coming back to a computer you watched in the last 30 minutes reconnects rather than asking you to wake it again.

From **Requests**, a Task working on the computer offers **Take over the computer**; a step-in shows its last picture and
**Take over**.

## Sign-ins on the computer

**Set up sign-ins** opens a live session on the real sites: sign in yourself, then **Done — save and let it sleep**. Workser
says plainly that it can't see what you type.

Afterwards it offers **Keep these logins safe?** — save a site's login in Credentials so an AI agent can sign in again after a
reset. Sign-ins made only in the session live on the computer and are lost if it is reset.

## Sleep, sign out, reset

| Action | What it does |
| --- | --- |
| **Stop computer** | Puts it to sleep now and stops using computer time. Sign-ins and files stay; **Wake** brings it back. If an AI agent is working, that Task stops first. |
| **Sign out of everything** | Signs out of every site on the computer and deletes its restore points. Saved logins in Credentials stay. |
| **Reset computer** | Erases the computer and starts fresh: files, apps, browser data, sign-ins on it, and its restore points. Logins and keys in Credentials stay, and saved work in the project is kept. |

Reset cannot be undone: "Everything on the computer: files, installed apps and browser data." A site whose login is saved in
Credentials signs in again when needed; one that was only signed in on the computer needs a new sign-in.

## Updates and restore points

**Manage** shows the computer's state, who it is for, what it is doing and when it was last used, plus **Update computer**,
**Try the update again** and **Go back to before the last update**. An update takes about five minutes and takes a restore
point first.

Restore points are taken when a Task or a setup ends. A reset or a sign-out deletes them.

## What it costs

- **27.3 credits an hour while it is awake, billed per second.** Asleep, it costs nothing.
- If a plan includes monthly computer time, it shows as **included time left**; after that, the same per-hour rate applies.
- Setting up sign-ins uses the same time: "Setting up · 12 min · from included time, then 27.3 credits an hour."

## When there is no screen

Not every Task runs on a computer. A Task in a sandbox works in its own workspace with no screen to watch; the same tab shows
its workbench and the files it made instead.

## If something is wrong

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| The screen says **Asleep** | It went to sleep to stop using time | **Wake computer** |
| **Needs a restart** | An update or a stuck process | **Manage → Update computer**, or reset |
| You cannot take control | An owner or admin holds it, or the link ended | Ask them to give it back, or take control again |
| An AI agent cannot sign in after a reset | The login was only on the computer | Save it in [Logins](/using/logins), then sign in |
| "Only an owner or admin can add, change or remove computers." | Your role | Ask an owner or admin |
| A Task runs with no screen | It is in a sandbox, not on the computer | Nothing; its files are in the Task |
