**The cloud browser is a separate browser your AI agents can use for web work, kept apart from the project's computer.** It
stays signed in to the sites you set up, can be watched or put to sleep, and is split into **profiles** so social and finance
accounts do not share a session.

**It is not sold today.** Projects that have it can use it; everywhere else, web Tasks use the computer's own browser. The
Browser tab says so plainly: **"Not switched on for this project yet. Until it is, web tasks use the computer's own
browser."**

## The Browser tab

Open **Browsers** from the "+" launcher. The tab has:

- **The browser's state**, with **Open browser**, **Watch** / **Stop watching**, **Put it to sleep** and **Sign out
  everywhere**.
- **Signed in to**: the sites it keeps signed in. "Sign in to a site once, and every task that needs it starts signed in."
- **Where it runs**: the region nearest the sites your team uses; it moves there the next time it wakes.
- **Profiles**: **Project browser** plus any profiles you made.

Asleep it costs nothing; awake, it is billed by the minute from your credits. **Put it to sleep** when you are done.

## Profiles

A profile keeps its own sign-ins and decides which AI agents may use it.

- **Project browser** is the project's default: every AI agent uses it, except one that keeps its own sign-ins.
- **Each other profile** shows how many AI agents use it, a switch per AI agent, and its sign-ins.
- Creating one: **New profile name** (for example "Social" or "Finance"), then **Create profile**.
- Changing who may use a profile stops that profile's live browser: "Changing access stops that profile's live browser."

The section's promise: "Each profile shares its sign-ins with the AI agents you select. Keep social and finance accounts in
separate profiles."

## Signing in

- **Sign in to a site** on the profile's own page, then come back and choose **Done signing in**. Sign-ins are saved for that
  profile.
- The AI agents switched on for the profile then start every task signed in.
- A profile with no sign-ins says: "No saved sign-ins yet. Set them up below, and every task in this profile starts signed
  in."
- **Sign out everywhere** signs every AI agent out of every site, after asking. Saved logins in
  [Logins](/using/logins) stay.

For a site that needs a password rather than a session, save it once in [Logins](/using/logins); the AI agent types it by name.

## Watching and control

- **Watch** shows the browser live. You can also take control when an AI agent is working there; the same hand-back rules
  as the cloud computer apply.
- **Put it to sleep** stops the billing for the browser. It wakes when a Task needs it.
- A browser that is asleep or out of view says so ("Paused while it is out of view — scroll back to it to carry on signing
  in"), rather than looking broken.

## What is not sold today

- The **cloud browser** is not in the plan cards or the add-on list today. A project that already has it keeps its profiles,
  and extra profiles are managed in **Profiles** in the tab.
- Projects without it see **"Not switched on for this project yet"**, and web Tasks use the computer's browser.

## If something is wrong

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| **Not switched on for this project yet** | The project has no cloud browser | Web tasks use the computer's browser; use [Logins](/using/logins) |
| **Couldn't reach the cloud browser just now** | The service is restarting | **Try again**; nothing changed and sign-ins are kept |
| A task is signed out of a site | The site ended the session | Sign in once in the profile; it signs in again by itself next time |
| An AI agent cannot use a profile | It is switched off for that profile | Switch it on in **Profiles** |
| **Paused while it is out of view** | You scrolled away during sign-in | Scroll back to the browser |
