## Our commitment

We want Workser to be usable by as many people as possible, including people with disabilities. We're working toward conformance with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA, using standard accessible components (Radix UI primitives) as a foundation.

## Current status

We have not yet completed a formal WCAG conformance audit. We're not claiming full AA conformance today — this statement will be updated with a specific conformance level once an audit has been completed.

## Known limitations

Some parts of the product — particularly the visual workflow canvas and web app builder's design surface — are inherently visual/spatial tools and may be difficult to use with a screen reader alone. We're evaluating how to improve this over time.

## Feedback

If you encounter an accessibility barrier using Workser, tell us at [support@workser.ai](mailto:support@workser.ai) with a description of the issue and, if possible, the assistive technology you were using.
