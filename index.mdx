**Workser brings coding agents, project context and managed cloud services together so you can build, publish and keep improving software.** Start with Workser Code for the desktop development workspace, or use these guides to find an existing web-platform feature.

Connect Claude Code, Codex, Cursor Agent, GitHub Copilot or OpenCode, or use Workser Code's built-in agent. Connected agents use their own provider accounts. The built-in agent uses Workser credits for paid models.

## The wider Workser platform

| Area | Use it for |
| --- | --- |
| [Workser Code](/code/overview) | Software development with specialist roles, project channels, tasks, preview and release |
| [Workser Cloud](/code/infrastructure) | Hosting, Postgres, app user authentication, files, domains and environment configuration |
| [Agent Cloud](/code/agent-cloud) | Hosted agents called from your own software |
| [Workser Business](/workser-business/overview) | The existing web platform, AI Employees, business records and workflows |
| [Computer Use](/workser-desktop/computer-use) | Desktop screen and input tasks with the permissions that capability requires |

Your account and organization connect the product areas. They serve different jobs and can have different usage rules; a connected coding-agent subscription does not cover every hosted Workser service.
