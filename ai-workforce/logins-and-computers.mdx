**Every project has a shared cloud computer that all its AI agents use and stay logged in on, so you set up logins once.** The work keeps going when your laptop is closed.

## The shared cloud computer

AI agents use websites and desktop apps on the cloud computer the way a person would. You can open an AI agent's side panel to watch its screen live, or take over the cloud computer and hand it back.

- **Dedicated computers:** add one for $5 a month each and choose which AI agents may use it.
- **Computers at once:** higher plans run more cloud computers at once. Only computers working now count; a paused computer frees its slot.
- **Cost:** cloud computer time is paid from your credits on every plan, 25 credits an hour, billed per second.

| Plan | Cloud computers and sandboxes at once |
| --- | --- |
| Free | 1 |
| Starter | 5 |
| Pro | 10 |
| Team | 5 per person, shared |

## The cloud browser

Each AI agent can work in a cloud browser that stays signed in to your web apps. Browser profiles keep different sets of logins apart, for example a **Company** profile for shared business accounts. Each plan includes some profiles, the Company profile among them; a paid plan can add more for $2 a month each.

## Logins

Save a login once and every AI agent you allow can use it.

- Passwords are encrypted. AI agents fill them in by name and **never see them**.
- You choose which AI agents may use each login, on the AI agent's **Browser** tab.
- If a login expires, the task says Stuck and tells you which one to update.

## Private sandboxes

Work that needs it can run in a private sandbox, separate from your own apps and files. A sandbox is set up for its kind of work, such as documents, design or code, and is removed when the task ends.

## Your data

Your work stays inside your organization. Tasks run on your project's cloud computer or in a private sandbox, and saved logins are encrypted. See [Security & Trust](/security/whitepaper).
