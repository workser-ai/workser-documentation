## For enterprise teams

- **Data isolation**: confirm your organization is on a paid tier if per-project database isolation is a requirement for your security review — see [Security & Trust](/security/whitepaper#multi-tenancy-and-data-isolation).
- **Access control**: deleting a project requires a dashboard session or a management-scoped API key — an automation key alone can't delete a project.
- **Deletion**: deleting a project tears down its dedicated database and file storage; the project record is archived (not row-deleted) for billing/audit history.

## For self-serve builders

You don't need to think about infrastructure — the database, hosting, and domain setup happen automatically per project. Credits are consumed by AI build/iteration actions; see [Payments & Billing](/consumer/payments-billing).
