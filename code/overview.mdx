**Workser Code brings your coding agents together as one AI tech team.** Describe the software you need, review the plan, follow the tasks and try the result. Workser manages the project context and the cloud services your software needs to run.

Connect Claude Code, Codex, Cursor Agent, GitHub Copilot or OpenCode, or choose the built-in Workser Code agent. You can assign different agents and models to different roles.

## From the first request to the next release

<Steps>
  <Step title="Describe the result">
    Explain who the software is for, what they should be able to do and how you
    will know it works.
  </Step>
  <Step title="Review the plan and team">
    Workser organizes goals, tasks and role assignments. Thirteen specialist
    roles cover planning and design, building, testing, release and improvement.
  </Step>
  <Step title="Build and check">
    Follow progress in project channels. Inspect the preview, changed files and
    available check results. Ask for revisions against the same project.
  </Step>
  <Step title="Approve the release">
    Production deployment requires your approval. After launch, request fixes
    and improvements with the project's documents, decisions and handovers still
    available.
  </Step>
</Steps>

## One project, several apps

Build **web apps, mobile apps, API services, and data apps**. A project can contain several apps sharing its database, files, connections and environment configuration. Local development needs your computer running; published apps run on their hosting.

## Choose how the coding agent is paid for

| Option                      | Model usage                                          | Workser plan                                                      |
| --------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------- |
| Connected coding agent      | Your provider account, subscription and usage limits | Pays for Workser's workspace and cloud allowance                  |
| Built-in Workser Code agent | Uses your organization's Workser Code credits        | Every plan includes credits: Starter 1,800 and Pro 10,000 a month |

Workser Code is included in every Workser plan. Start free with 50 credits; paid plans start at **$20 a month** with a 7-day money-back guarantee. See [Pricing](/code/pricing) for credits, cloud limits and hosting rates.

## Workser Code and the wider platform

Workser Code is the software development workspace. The [AI Workforce](/ai-workforce/overview) docs cover the AI agents that run the rest of your business, including the [cloud computer and cloud browser](/ai-workforce/logins-and-computers) they work on.

Platform statistics include work from across Workser. Existing web app and deployment totals are not counts of apps built specifically in Workser Code. [How platform statistics are counted](/code/platform-stats).
