**Workser Code is included in every Workser plan.** One plan covers your AI workforce, Workser Code and the hosting your apps run on. The full plan comparison, add-ons and charging rules are in [Plans, credits and add-ons](/ai-workforce/plans-and-credits); this page covers what is specific to building and hosting apps.

Every paid project has its own dedicated Postgres database. Multiple apps in a project share that database and its file storage. Domain registration is bought separately, and you configure the domain's DNS records.

Paid plans have a 7-day money-back guarantee: your plan price back, minus credits you used. It replaces the old Spark free trial.

**Spark** ($10 a month, 800 credits) is sold only in the desktop app, and current Spark customers keep it.

**Enterprise** has custom pricing, capacity and credit terms. [Talk to us](https://workser.ai/contact).

## Cloud overage

Every paid plan includes one free hosting base, per organization per month: **0.5 GB database, 5 compute hours, 10 GB files, 2 GB transfer and 500 workflow runs**. Past that, hosting is paid from your credits:

| Cloud resource | Credits |
| --- | --- |
| Database storage | 200 per GB a month |
| Database compute | 40 per hour |
| File storage | 10 per GB a month |
| Data transfer (egress) | 60 per GB |
| Workflow runs | 100 per 1,000 runs |

100 credits = $1 when you pay. For example, 10 GB of transfer past the free base is 600 credits, or $6.

Project, app and domain limits need a plan upgrade rather than credits.

## Workser Code credits

### Connected coding agents

Claude Code, Codex, Cursor Agent, GitHub Copilot and OpenCode use the account configured in their own CLI. Those model calls do **not** spend Workser credits. Their provider can still charge you or apply subscription limits.

### The built-in Workser Code agent

You do not need a separate AI subscription to use the built-in agent. Its model usage is paid from your organization's credits:

- Each model call is charged the moment it finishes, in the units the provider returns.
- A live meter shows the credits a task uses as it runs.
- A task that fails pays for what actually ran.
- Plan credits refresh every month and unused ones expire. Credits you buy never expire: 1,000 for $10.

Free runs on one fast model. Paid plans choose premium AI models.

## Agent Cloud (Beta) and other hosted AI

[Agent Cloud](/code/agent-cloud) runs hosted agents on Workser infrastructure. Their model usage, sandbox and runtime are charged in credits as they run, separately from any connected coding-agent subscription.
